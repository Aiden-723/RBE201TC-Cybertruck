# 历史源码归档

当前开发入口在仓库根目录backend/frontend/tools等目录。本目录保存开发期间的不同源码、旧候选、原件和一次性诊断/部署脚本，用于了解演变与查找回归；不自动加载，不作为当前部署入口。

[完整历史索引](../docs/HISTORY_INDEX.json)列出原outputs相对位置、发布位置、原始SHA以及是否去重。相同内容只存一次，可能指向当前源码或另一份历史文件。公开副本只泛化个人主目录；旧硬件参数、旧默认速度和旧控制逻辑仍保持历史原意，不能当成最新需求。

history按原开发任务分类：UI、V6/V7、探头方向、16模式、连续纠偏、IMU转弯、Wi-Fi/USB、限速与底层审计等。历史目录中的prepare/deploy/install脚本通常依赖未公开的当时payload、日志和主板状态；不能直接用于现在的车辆。不会通过CI去执行这些硬件脚本。

没有包含完整聊天、原始传感器试验数据、密码、私钥、厂家网页镜像、安装环境和重复二进制包。代码归档索引不代表已运行每个历史脚本。
